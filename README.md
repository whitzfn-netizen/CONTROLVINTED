# Control de cuentas Vinted

Panel para controlar cuentas de Vinted: accesos, SIM, móviles y dinero retirado y pendiente.

- Los datos se guardan **solo en el navegador** donde se usa (no se suben a este repositorio ni a ningún servidor).
- Las contraseñas, PIN y códigos se cifran en el navegador con una clave maestra.
- Para pasar los datos a otro dispositivo, usa **Exportar CSV** e **Importar CSV**.
