# Control de cuentas Vinted

Panel para controlar cuentas de Vinted (accesos, SIM, móviles y dinero) y deudas.

- Los datos se sincronizan entre todos tus dispositivos guardándolos **cifrados** en la rama `datos` de este repositorio.
  Cómo activarlo: [GUIA-SINCRONIZAR.md](GUIA-SINCRONIZAR.md).
- Sin conocer la clave de acceso, el archivo de datos es ilegible. El token de GitHub que permite guardar también va cifrado.
- Las contraseñas, PIN y códigos se cifran además con la clave maestra antes de guardarse en ningún sitio.
